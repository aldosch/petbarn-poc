GraphQL Mesh API

Hive Gateway runtime serving the Countries subgraph plus ecommerce types. Playground at /api/graphql.

  • products(collection: String)query — catalog for the storefront
  • product(handle: String!)query — product detail page
  • collectionsquery — navigation
  • cart(id: ID!)query — cart state for storefront + checkout
  • storeLocationsquery — aggregated with the Countries subgraph
  • createCart / addToCart / updateCartLine / removeCartLinemutations — cart lifecycle
  • placeOrder(cartId: ID!, email: String!)mutation — checkout
  • countries / country(code: ID!)query — Countries subgraph (the getting-started source)
